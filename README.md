## 为什么机房 IP 总是被封

做数据采集、比价、广告验证，或多账号矩阵运营的人，大概率都遇到过：

- 请求一多就返回 429 / 403
- 账号刚登录就被风控、要求验证
- 同一段 IP 上的请求被整批识别

根因是：**机房 IP 段（数据中心）早被各大平台标记为“非真实用户”**。平台只要看到流量来自已知机房段，就会直接限流或拦截。

## 动态住宅IP 是什么

动态住宅IP，指的是来自真实家庭宽带网络的 IP，并且**每次请求自动更换**。因为它看起来和普通人上网一样，所以最难被识别和封禁。

核心特征：

- 来源是真实家庭宽带，不是机房
- 按请求或按时间动态轮换，一个 IP 不会用太久
- 天然“像真人”，适合需要长期稳定访问的场景

## 三类 IP 怎么选

| 类型 | 来源 | 防封能力 | 适合场景 |
|------|------|----------|----------|
| 数据中心 IP | 机房 | 弱，易被标记 | 普通访问、对防封无要求 |
| 静态住宅 IP | 家庭宽带，固定不变 | 中 | 需要固定身份的登录 |
| 动态住宅 IP | 家庭宽带，自动轮换 | 强 | 爬虫、多账号、防关联 |

结论：如果你的问题是“被封”，优先看**动态住宅 IP**。

## 选服务商看这几点

1. **来源是否透明**：正规服务会说明 IP 来自真实家庭宽带、有授权关系，而不是来路不明的共享池。
2. **轮换机制**：是否支持按请求换 IP，换 IP 的粒度能不能控。
3. **协议支持**：至少要支持 Socks5 和 HTTP，方便接爬虫、指纹浏览器、社媒工具。
4. **覆盖国家**：看你业务需要的地区是否覆盖。
5. **计费方式**：按流量还是按时长，中小用量按流量更灵活。
